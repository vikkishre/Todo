# Todo
Todo List Application in React
This is a React practice project built using React hooks, props, and Material UI for styling. The project showcases basic React concepts like state management, functional components, and the usage of hooks (such as useState and useEffect). It fetches dummy data from a JSON API to display a list of to-dos.

The app is a static todo list where the data is pre-populated and fetched from a mock JSON API. While it does not allow dynamic actions like adding or updating to-dos, it serves as an excellent exercise in learning React and working with Material UI components.

This project was implemented while learning React from Sangam Mukherjee's YouTube channel, and it provides a simple foundation to further enhance with dynamic CRUD operations.
